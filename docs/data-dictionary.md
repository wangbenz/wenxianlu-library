# JSON 资料字段与版本

本工程无资料数据库表。具体约束由 [schema/](../schema/) 与加载器共同定义，所有对象禁止未知字段。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| type | 英文枚举 | world/region/place/realm/root/item/art/faction/character/event |
| key | 稳定英文编号 | 类别内唯一，与文件名一致；新编号是新身份 |
| name | 中文字符串 | 展示名称，不作为身份 |
| phase | 1、2、3 | 记录的内容阶段，不等于 API 或项目版本 |
| public | 分类限制的对象 | 可供玩家展示，允许标记统一来源 |
| rules | 分类限制的对象 | 枚举、数量、引用；明确注释字段仅作解释，不作关键词裁决 |
| narration | 分类限制的对象 | AI 写作提示，不出现在公开投影 |
| secret | 分类限制的对象 | 隐藏内容，不出现在公开投影 |
| revision | 接口附加字符串 | `sha256:<content_hash>`，稳定标识而非递增整数，不写入资料文件 |
| content_hash | 接口附加字符串 | 规范化完整条目的 SHA-256，64 位十六进制 |

引用固定为 `类别:key`。跨文件校验保证目标存在、类别正确、目标阶段不晚于引用方。境界、价格、灵根概率、地点树等交叉约束见 README；具体数值是待审核资料，不由服务执行玩法结算。

manifest 的 format_version 为 1，published_phase 表示已上线的最高阶段，categories 是全部文件清单。加载所有文件后，仅为已启用阶段建立类别、阶段和编号索引。列表及批量响应的顶层指纹标识本次活动快照，各记录另有自己的版本指纹。

旧 API 的整数 revision、模型字段和历史查询 URL 与本接口不兼容，不能将旧存档的版本值自动改写成新格式。当前游戏需要另行适配并保留原冻结内容；本 PR 不触碰游戏存档。
