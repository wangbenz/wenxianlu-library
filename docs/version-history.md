# 版本记录

## 0.4.0：JSON 文件资料服务（2026-11-07，第一阶段 PR，待审核）

- 替换 Django/DRF 运行层为 FastAPI，移除资料模型、维护后台和数据库内容存储；保留原许可证和原本地上游历史。
- 十类单条 JSON Schema 与 manifest，完整加载和交叉校验、不可变快照、编号/类别/阶段索引。
- 公开投影、受服务令牌保护的内部读取、独立运维令牌重载；失败保留旧快照，成功原子替换。
- 内容版本采用指纹，不手写版本；只提供当前版本，游戏端冻结其采用的完整资料。旧路径与整数 revision 不兼容，未切换现有游戏服务。
- 显式旧 JSON 迁移规划/映射工具，保留旧文件为测试输入，不连接旧数据库、不覆盖已有输出。
- 12 条闭合评审样例包含六类灵根草案分布；不是第一批完整内容。完整内容、旧条目逐条改写及完整十一境界清单的缺项待格式审核后处理。

已执行 `uv sync --locked`、文件全量校验、72 项 pytest、Ruff 和独立进程 HTTP 检查，均通过。pytest 有一条 Starlette 对 HTTPX 测试客户端的弃用提示，不影响本轮结果。未执行镜像构建、远程 CI、生产部署、游戏接入或模型回放。
